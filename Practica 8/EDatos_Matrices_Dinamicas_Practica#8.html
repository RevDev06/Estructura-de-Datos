Estructuras de Datos Estáticas Lineales¶

Las estructuras de datos lineales son aquilles en las que los elementos se organizan uno después de otro, formando una secuencia¶

¿Qué es una Matriz Estática?¶

Una matriz estática es una estructura de datos que tiene un número fijo de filas y columnas, definidas desde el momento que se crean.¶

Imágen Digital¶

Digitalmente, una imágen puede representarse como una matriz especialmente cuando hablamos de procesamiento de imágenes.¶
